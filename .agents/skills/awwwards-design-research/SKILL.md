# Awwwards Design Research & Creative Direction Skill

This skill enforces a rigorous design research methodology before coding any digital experience, preventing generic AI UI patterns and ensuring world-class art direction.

---

## 🔍 Pre-Design Research Protocol

Before writing HTML, CSS, or component code:

### 1. Benchmark Award Winners
- Review current **Awwwards Site of the Day / Site of the Month**, **FWA of the Day**, and **CSS Design Awards**.
- Identify 2–3 reference experiences in the same or adjacent industries (e.g., Luxury Food & Beverage, High Fashion, Architectural Portfolios).

### 2. Deconstruct Core Pillars
Analyze and document the following:
- **Typography**: Display font character, scale contrast, letter-spacing, editorial column layout.
- **Composition**: Use of asymmetry, negative space, overlapping layers, and framing.
- **Color Harmony**: Restricted palette (60% canvas, 30% structural/ink, 10% high-intent accent).
- **Navigation**: Unobtrusive, minimal, contextual, or gesture-based.
- **Scroll & Storytelling**: Pinned visual anchors, horizontal tracks, reveal masking, velocity skewing.
- **Tactile Micro-Interactions**: Custom cursor behaviors, magnetic buttons, hover states that feel alive.
- **Visual Rhythm**: Balancing quiet, high-whitespace reading zones with grand cinematic showcases.

### 3. Synthesis (Zero Plagiarism)
- **DO NOT COPY ANY SITE.**
- Extract the underlying mechanics and principles.
- Synthesize an original aesthetic language that directly serves the brand's unique narrative.

## 🚫 Anti-Generic Checklist

Review your planned design against this checklist. If any are present, redesign immediately:
- [ ] No generic purple/cyan/blue linear gradients
- [ ] No arbitrary cards nested inside cards
- [ ] No unmotivated glassmorphism
- [ ] No excessive pill buttons
- [ ] No default Inter or system sans typography for primary headings
- [ ] No generic centered headline + subheadline + 2 buttons hero
- [ ] No repetitive 3-column feature grids
- [ ] No meaningless floating blobs or shapes
- [ ] No standard OS emojis (use bespoke line-art SVGs only)
